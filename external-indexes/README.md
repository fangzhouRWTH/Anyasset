# External library index registry

Commit metadata-only version indexes here as <library-id>/<version>.json.
Generate them with assetctl library-index; see ../EXTERNAL_LIBRARIES.md.

Do not place external payloads, local absolute roots, credentials, or download
tokens in this directory. Source files stay in separately managed directories.
No external libraries are registered by default. Each team explicitly chooses
which index metadata is appropriate to share in this repository.
