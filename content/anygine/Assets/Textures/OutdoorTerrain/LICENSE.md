# Outdoor terrain texture sources

The eight texture sets listed in `terrain-material-library.v1.json` are unmodified 1K map variants
from [Poly Haven](https://polyhaven.com/textures). Poly Haven publishes its assets under
[CC0 1.0](https://polyhaven.com/license).

The EXR maps are retained as high-dynamic-range source assets. Matching official JPEG normal and
roughness variants are included for the current Anygine RGBA8 runtime decoder. Base-color maps are
sampled as sRGB; OpenGL normal, roughness, and displacement maps are sampled as linear data.

Authorship and original asset links are recorded per set in the library manifest. Attribution is
not required by CC0, but the provenance is intentionally preserved.
